# Pilot acceptance — PRD §13.2

Pilot cut: one zone · prepaid default · scheduled + limited instant · Android-first rider · web kitchen/dispatch.

## Definition of done

- [ ] Customer in configured zone can discover haleem, place prepaid (or permitted COD) order, see accurate status, track rider, complete support flow
- [ ] Kitchen can accept, prepare, pack, label, hand off with stock/capacity protected against oversell
- [ ] Dispatcher can see exceptions and assign/reassign; rider completes pickup and OTP/proof delivery with low-connectivity recovery
- [ ] Every rupee traceable across order, payment/refund, rider earning, tip, COD (if enabled), payout ledgers
- [ ] No duplicate order, double charge, double refund, or double rider assignment in retry/concurrency tests
- [ ] Critical notifications, monitoring, audit, backup, incident, rollback procedures tested/documented
- [ ] App-store privacy disclosures, legal policies, food/outlet details, production support ownership complete or explicitly drafted with owners
